# 마케팅 대시보드 구조 분리본

`index(2).html`의 기능, 계산식, DOM 구조, 스타일 적용 순서를 유지하면서 CSS와 JavaScript를 역할별 파일로 분리한 버전입니다.

## GitHub Pages 적용

1. 기존 `adtool` 폴더의 `data`와 이미지 파일은 그대로 유지합니다.
2. 이 폴더의 `index.html`, `css`, `js`를 기존 `adtool` 폴더에 업로드합니다.
3. GitHub Pages 반영 후 브라우저에서 강력 새로고침합니다.

모든 내부 파일 경로는 GitHub Pages의 하위 경로에서도 동작하도록 `./` 상대경로를 사용합니다.

## 파일 역할

- `css/base.css`: 디자인 토큰, 초기화, 기본 요소
- `css/components.css`: KPI, 테이블, 탭, 모달, 차트 등 공통 UI
- `css/layout.css`: 헤더, 내비게이션, 전체 레이아웃과 반응형 보정
- `js/data/mappings.js`: 인타입·키워드 매핑과 관련 로더
- `js/core.js`: 데이터 파이프라인, 캐시, 공통 상태, 표와 탭 제어
- `js/insights.js`: 성과 진단과 상세 분석
- `js/keyword.js`: 키워드 매체 데이터 처리와 화면
- `js/display.js`: 디스플레이 매체와 리포트
- `js/app.js`: 초기 실행과 공통 알림

## 이번 단계에서 유지한 것

- 기존 화면 디자인과 DOM 구조
- 함수명과 전역 상태
- 계산식과 데이터 경로
- 탭 전환, 모달, CSV, 차트 동작 방식
- 기존 인라인 스타일

인라인 스타일은 화면을 바꾸지 않고 안전하게 분리하기 위해 이번 단계에서는 유지했습니다. 다음 디자인 정리 단계에서 공통 클래스 및 화면별 클래스로 이동하는 것이 안전합니다.
