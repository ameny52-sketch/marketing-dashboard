# 마케팅 성과 모니터링 대시보드

광고 매체별 성과(광고비·DB수·계약·평가업적)를 한곳에서 보는 사내 대시보드입니다.
빌드 도구 없이 `index.html`을 열면 그대로 동작합니다.

## 탭 구성

| 탭 | 내용 |
|---|---|
| 전체 | Daily DB 현황 — 날짜 × 매체별 성과 |
| 키워드 | 성과 진단 / 데이터 현황 (네이버·구글·다음) |
| 파워컨텐츠 | 성과 진단 / 효율 순위 / CPC 분석 / 데이터 현황 |
| 디스플레이 | 성과 진단 + 매체별(카카오페이·T멤버십·가스락·KT PASS) 영역·소재 성과 |
| 커스텀 보고서 | 행/열/지표를 직접 골라 만드는 피벗 표 + CSV |

## 실행

```bash
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속. (`file://` 로 열면 CSV 로드가 막힙니다.)

## 배포

`main` 브랜치에 push하면 GitHub Pages에 반영됩니다. 반영 후 브라우저 강력 새로고침이 필요할 수 있습니다.

`data/*.csv` 는 별도 자동화 스크립트가 매일 다시 만들어 커밋합니다.

## 데이터 출처

- **정적 CSV** (`data/`) — CRM 원본, 매체별 광고비. 자동화가 매일 갱신
- **구글시트 2개** — 광고그룹·인타입 매핑 / 디스플레이 인타입 참조표. 시트만 고치면 즉시 반영

자세한 매핑 관계는 `js/data/mappings.js` 맨 위 주석에 정리돼 있습니다.
